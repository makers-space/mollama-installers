# Mollama installers

Downloads for the Mollama desktop app. This repository holds only the installers; each release has the files for that version.

## Windows

Download `Mollama-Setup.exe` from the [latest release](https://github.com/makers-space/mollama-installers/releases/latest) and run it.

The installer is not signed yet, so Windows shows a warning first: choose **More info**, then **Run anyway**.

Not available yet.
